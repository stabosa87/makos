# MakOS
"MacOS at home"

**MakOS** is intended to be a MacOS alike distro made by someone who has never used MacOS but loves the architecture. (Though i don't like brew.)

It is a GNOME desktop built on [Universal Blue](https://universal-blue.org/)'s silverblue image.

Because **MakOS** is entirely reliant on upstream (it's just fedora silver blue with a couple preinstalled packages) you can expect it to *just work*!

``dbin`` is the choice of home package management for one reason. If you don't want it you don't gotta have it! It's independent of the distro and requires 1 single binary if you do want it. To get dbin run 
```sh
ujust install-dbin
```


### REQUIRED DEFAULTS
You need atleast
- 8 GB RAM
- 20 GB storage

Other than that your golden!

This repository started from the [Universal Blue image template](https://github.com/ublue-os/image-template).
